# Секундомер

Компактный секундомер-оверлей для Windows. В покое — одна строка поверх других окон;
каждый круг добавляет строку и растягивает окно вниз (до 8 строк, дальше прокрутка).

## Запуск

- `start-secundomer.vbs` — обычный запуск, без мелькания консоли (рекомендуется).
- `start-secundomer.bat` — то же самое, через `pythonw`.

Ярлык на рабочем столе (выполнить в PowerShell):

```powershell
$s = (New-Object -ComObject WScript.Shell).CreateShortcut("$env:USERPROFILE\Desktop\Секундомер.lnk")
$s.TargetPath = "C:\Users\Lenovo\Documents\ClaudeC\Projects\secundomer\start-secundomer.vbs"
$s.WorkingDirectory = "C:\Users\Lenovo\Documents\ClaudeC\Projects\secundomer"
$s.Save()
```

Требуется установленный Python (проверено на 3.12 с tkinter 8.6).

## Кнопки

| Кнопка | Действие |
|---|---|
| ▶ / ■ | старт и стоп (пауза с сохранением накопленного времени) |
| ⊕ | круг: текущий результат уходит строкой ниже, счёт начинается с нуля и сразу идёт дальше |
| ↺ | сброс: обнуляет таймер и чистит список |
| ✕ | закрыть (позиция окна сохраняется) |

## Горячие клавиши

Работают, когда окно в фокусе (клик по нему):

- `Пробел` — старт / стоп
- `Enter` — круг
- `Ctrl+R` — сброс
- `Ctrl+Q` — закрыть

Глобальных хоткеев (когда фокус в другом приложении) нет — для них нужна
сторонняя библиотека вроде `keyboard`, добавляется при необходимости.

## Управление окном

- **Перетаскивание** — за корпус или за поле таймера левой кнопкой.
- **Прозрачность** — колесо мыши над шапкой (от 35 % до 100 %).
- **Правый клик** — меню: «Поверх всех окон», «Копировать результаты»,
  «Сохранить в CSV…», «Сброс», «Выход».

Окно без системной рамки, поэтому его нет в панели задач и в Alt+Tab —
закрывать через ✕ или `Ctrl+Q`.

## Экспорт

- **Копировать результаты** — в буфер в виде `номер⇥отрезок⇥итого`, вставляется в Excel.
- **Сохранить в CSV** — разделитель `;`, десятичная запятая, кодировка UTF-8 BOM
  (Excel открывает без плясок с импортом).

## Файлы

- `secundomer.py` — само приложение.
- `config.json` — создаётся рядом при закрытии: позиция окна, прозрачность,
  режим «поверх всех окон». Удалить — вернутся настройки по умолчанию
  (правый верхний угол).

## Настройка внешнего вида

Константы в начале `secundomer.py`:

- `WIDTH`, `HEADER_H` — ширина окна и высота строки таймера (в логических пикселях,
  масштаб экрана применяется автоматически);
- `MAX_VISIBLE_ROWS` — сколько кругов видно до появления прокрутки;
- `FONT_TIMER`, `FONT_ROW`, `FONT_BTN` — шрифты;
- блок цветов `BG`, `FG`, `RUN`, `IDLE` и т. д.

Приложение объявляет себя DPI-aware, поэтому на экранах с масштабом 125/150 %
текст остаётся чётким, а размеры пересчитываются от реального DPI.
